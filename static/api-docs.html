📖 概述

AISHPerf 是「AI 芯片 × 模型」知识图谱系统，提供芯片搜索、画像、筛选、推荐能力。本 API 是其后端接口，底层为 SQLite 数据库，包含 5 张核心表：

表行数说明
chips1,098芯片全生命周期信息（27 家厂商，78 字段）
models1,370模型信息（来自 HuggingFace API）
chip_model_benchmarks2,103芯片×模型 推理/训练实测数据
chip_model_compatibility2,720芯片×模型 兼容关系
field_provenance12,677字段级来源溯源（每次写入/更新的记录）

基础信息

项值
基础路径/api/v1（与前端同源部署）
数据格式JSON，UTF-8 编码（Content-Type: application/json）
认证公开只读 API，无需认证。/api/v1/chat 使用服务端配置的 DeepSeek API Key，客户端无需提供。
分页统一使用 limit / offset，limit 默认 50、上限 2000
错误格式HTTP 404/500，响应体 {"detail": "错误说明"}

通用约定

分组字段格式

详情类端点（芯片画像、评测、兼容记录）返回分组结构，而非扁平字段。例如评测记录分为 identity / test_metadata / inference_metrics / training_metrics / meta 组。仅包含有值的分组（meta 始终返回），取值时需注意分组可能缺失。

数值与空值

为灵活性考虑，数据库中绝大多数字段以 TEXT 存储（如 "610"、"192"）。无数据的字段返回 null。前端调用时建议做类型转换与空值容错。

来源溯源（field_provenance）

所有字段的写入/更新均记录来源。查询参数 source_type 枚举：

official_datasheetofficial_newsvendor_claimbenchmark_suitecommunityweb_crawlllm_curated

置信度 confidence 枚举：high / medium / low。

兼容状态枚举

compat_status：verified（实测验证）/ vendor_claimed（厂商宣称）/ community（社区）/ unsupported（不支持）。

未发布芯片

未公开发布芯片标记为 production_status="未公开发布" 且 is_released="0"，前端半透明显示并带 ⚠ 标签。

💬 智能助手

POST/api/v1/chat

AI 芯片选型助手：调用 DeepSeek（默认模型 deepseek-v4-flash），通过工具调用查询数据库、执行 CLI，返回流式 SSE 回复。

请求体（JSON）

{
  "messages": [
    {"role": "system", "content": "（可选）系统提示词"},
    {"role": "user", "content": "我想训练 Qwen2.5-7B，国产优先，给个方案"}
  ],
  "model": "deepseek-v4-flash"   // 可选，缺省用服务端配置
}

响应（text/event-stream，SSE）

流式事件格式，每行 data: {…}，以 data: [DONE] 结束：

data: {"type": "thinking"}                                        // 正在调用工具
data: {"type": "text", "content": "推荐使用 "}                      // 文本增量
data: {"type": "text", "content": "昇腾910C…"}
data: [DONE]
💡 工具调用过程对用户不可见（前端跳过 tool_* 事件）。响应头已关闭缓冲（X-Accel-Buffering: no），适合流式输出。

🔍 芯片

GET/api/v1/chips

芯片多条件筛选搜索，返回精简摘要字段（id、厂商、显存、算力等）。

查询参数

参数类型说明
search / keywordstring模糊搜索（厂商/型号/系列/架构），二者等价
vendorstring厂商（同时匹配 vendor 与 vendor_display）
regionstringdomestic（国产）| foreign（海外）
usagestringtrain | inference | both
vram_min / vram_maxnumber显存范围（GB）
tdp_maxnumber最大功耗（W）
price_maxnumber最大单价（万元/片）
interconnect_minnumber最小互联带宽（GB/s）
tierstringdatacenter | consumer | all
min_maturityint最小生态成熟度（0–5）
for_model + scenariostring按模型自动推算所需显存并筛选
limit / offsetint分页（limit ≤ 2000）
include_provenancebool是否附加字段溯源摘要

示例请求

curl "http://localhost:8000/api/v1/chips?region=domestic&vram_min=32&limit=1"

示例响应

{
  "count": 1098,
  "chips": [{
    "id": 32, "vendor_display": "AMD", "chip_series": "MI400X",
    "chip_model": "MI400X", "chip_type": "GPU",
    "architecture": "CDNA5", "process_node_nm": "3nm",
    "vram_gb": "432", "vram_type": "HBM4",
    "precision_perf": null, "tdp_w": null,
    "production_status": "待发布",
    "_benchmark_count": 0, "_compat_count": 0
  }]
}
GET/api/v1/chips/recommend

芯片推荐引擎（v2.0 十维评分）：按「模型 × 场景 × 约束」给出推荐候选及评分明细。

查询参数

参数类型说明
model（必填）string模型名称（模糊匹配，如 Qwen2.5-7B）
scenariostringtrain（训练，默认）| inference（推理）
training_daysnumber目标训练天数
training_tokensnumber训练数据量（T tokens，缺省自动估算）
sla_tpsnumber推理吞吐目标（tok/s）
tierstringdatacenter | all
max_cards / min_cardsint卡数硬约束（上限/下限，下限取 2 幂次）
max_pricenumber单价硬约束（万元）
min_maturityint成熟度硬约束（0–5）
prefer_domesticbool国产优先
prefer_vendorstring厂商偏好
tco_weightfloatTCO 权重（0.0–0.3，默认 0）
limitint返回条数（≤ 20，默认 5）

示例请求

curl "http://localhost:8000/api/v1/chips/recommend?model=Qwen2.5-7B&scenario=inference&prefer_domestic=true&limit=1"

示例响应

{
  "model": "Qwen/Qwen2.5-7B-Instruct | Dense | 7.6B params",
  "candidates": [{
    "id": 6, "vendor_display": "NVIDIA", "chip_model": "B200 SXM 192GB",
    "vram_gb": "192", "vram_type": "HBM3e",
    "precision_perf": "FP16 Tensor: 2250 TFLOPS | BF16 Tensor: 2250 TFLOPS …",
    "tdp_w": "1000", "interconnect_tech": "NVLink 5.0 …"
  }]
}
💡 MoE 模型自动使用「激活参数」估算显存（如 Qwen3.5-397B-A17B 按 17B 估算）。模型不存在返回 404。
GET/api/v1/chips/{identifier}

芯片完整画像：78 字段分 14 组 + 评测数据 + 兼容模型 + 字段溯源。

路径参数

参数说明
identifier纯数字 = 按 ID 精确查询；否则按名称模糊匹配（chip_model → 多字段 → 英文别名）

示例请求

curl "http://localhost:8000/api/v1/chips/5"

示例响应（结构）

{
  "chip": {                      // 分组字段：identity / architecture / memory / …
    "identity": {"id": 5, "vendor": "NVIDIA", "chip_model": "A100 SXM4 80GB", "chip_type": "GPU", …},
    "architecture": {"architecture": "Ampere", "process_node_nm": "7", "foundry": "TSMC", …},
    "memory": {"vram_gb": "80", "vram_type": "HBM2e", "vram_bw_gb_s": "2039", …}
  },
  "benchmarks": [ { "identity": {"model_id": "Qwen/Qwen2.5-7B-Instruct"},
                    "test_metadata": {"suite_name": "community", "workload_type": "inference", …},
                    "inference_metrics": {"throughput_tok_s": "610", "memory_peak_mb": "65000"} } ],
  "compatibilities": [ { "identity": {"model_id": "Qwen/Qwen2.5-7B-Instruct"},
                         "compat_details": {"compat_status": "verified", "framework": "vLLM", "precision": "FP16"} } ],
  "field_provenance": { "vram_gb": { "history": [ { "source_type": "official_datasheet", … } ], "update_count": 1 } }

💡 benchmarks / compatibilities 均为分组结构；field_provenance 以字段名为键的索引。芯片不存在返回 404。

🔎 来源溯源

GET/api/v1/provenance

字段级溯源记录查询：每次字段写入/更新都有一条记录（来源 URL、新旧值、置信度）。

查询参数

参数类型说明
tablestringchips | models | chip_model_benchmarks | chip_model_compatibility
row_idstring行 ID
fieldstring字段名（模糊）
source_typestring来源类型（见通用约定）
confidencestringhigh | medium | low
is_officialstring0 | 1
limit / offsetint分页

{
  "count": 12677,
  "records": [{
    "id": 14098, "table_name": "chip_model_benchmarks", "row_id": "212",
    "field_name": "_batch", "new_value": "MI355X",
    "source_type": "benchmark_suite",
    "source_url": "https://github.com/SemiAnalysisAI/InferenceX/…",
    "source_detail": "Migrated from parse11 MLPerf data",
    "confidence": "high", "is_official": "0",
    "updated_at": "2026-07-30T18:48:46", "notes": "MLPerf benchmark migration"

}

📎 附录

常用 curl 示例

# 搜索国产显存≥32GB 的芯片
curl "http://localhost:8000/api/v1/chips?region=domestic&vram_min=32"

# 查看 A100 完整画像（含评测/兼容/溯源）
curl "http://localhost:8000/api/v1/chips/5"

# 推理场景推荐 Qwen2.5-7B
curl "http://localhost:8000/api/v1/chips/recommend?model=Qwen2.5-7B&scenario=inference"

# 查询 H100 的兼容记录（含评测证据）
curl "http://localhost:8000/api/v1/compat?chip=H100&has_benchmark=true"

# 调用 AI 助手
curl -N -X POST http://localhost:8000/api/v1/chat \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"训练 Qwen2.5-7B，3天完成，国产优先"}]}'

技术栈

  • 后端：FastAPI + Uvicorn
  • 数据库：SQLite（5 表，全部 TEXT 字段，无强约束）
  • 交互式 API 调试：Scalar（/docs）
  • 智能助手：DeepSeek API（默认 deepseek-v4-flash）
